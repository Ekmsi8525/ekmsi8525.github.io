⚙️ How It Works

You might wonder what "decompiled" means. Let's break it down in simple terms. A game on a PlayStation disc is essentially compiled code — ones and zeroes that the console's hardware understands. Decompilation is the process of translating that binary code back into a readable programming language that humans can understand and modify.

Our team (and the contributors behind this open-source project) accomplished that for Serial Experiments Lain. The output is a playable version of the game that runs like the original, but is now a modern application. For you, this means no configuration, no compatibility patches, and no extra software.
